# RRS-research-topic

1. Listar alegações necessárias para cumprir a promessa.
2. Para fato atual/técnico/controverso, pesquisar fonte primária atual.
3. Registrar: alegação, fonte, data, trecho suportado, limite e classificação (`fact`, `inference`, `hypothesis`).
4. Encontrar pelo menos uma aplicação prática ou demonstração.
5. Se não houver evidência suficiente, reduzir a promessa ou usar placeholder.

Aceite: nenhuma alegação central aparece como fato sem evidência rastreável.
