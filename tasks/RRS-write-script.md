# RRS-write-script

1. Escrever para uma pessoa, em fala natural.
2. Usar hook aprovado literalmente ou alterar apenas com nova aprovação.
3. Entregar uma unidade nova por bloco.
4. Fechar o loop no payoff.
5. Usar exatamente um CTA coerente com o objetivo.
6. Gerar legenda sincronizada igual à fala; nenhum texto visual adicional.
7. Manter 25–40 s por padrão; dividir em série se a precisão exigir.

Aceite: roteiro gravável, sem repetição, sem promessa não entregue e sem texto visual extra.
