# RRS-design-structure

Escolher um modelo do catálogo conforme a função, não pela frase:

- educacional: hook → qualificador → 2–3 passos → payoff → CTA;
- contraste: lado A → lado B em pares → síntese → CTA;
- demonstração: problema → procedimento → mudança → limite → CTA;
- storytelling: tensão → contexto → conflito → virada → lição → CTA;
- atualização: o que mudou → para quem importa → teste → limite → CTA.

Apresentar apenas blocos e função. Aceite: estrutura aprovada antes das falas.
