# Base de roteiros para Reels

## Como usar esta base

Esta pasta é o acervo de decisão para criar roteiros, não uma coleção de frases para copiar. Antes de escrever um Reel, comece por `01`, escolha uma estrutura em `02` e use `04` depois de publicar.

## Princípios que governam a base

1. Uma ideia principal por Reel.
2. Gancho é promessa de atenção; roteiro é a entrega dessa promessa.
3. Estrutura pode ser adaptada; frases, histórias e resultados de outra pessoa não devem ser copiados.
4. Número, teste, autoridade ou resultado só entra quando é verdadeiro e explicável.
5. O histórico de cada publicação deve informar o próximo roteiro.

## O que ainda não existe

Ainda não existe uma skill. Esta base será a matéria-prima para criá-la depois que o público inicial, o objetivo comercial e a rotina de produção forem confirmados.
