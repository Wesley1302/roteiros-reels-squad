# Contribuindo

## Fluxo

1. Crie uma branch curta a partir de `main`: `feat/...`, `fix/...`, `docs/...` ou `chore/...`.
2. Faça alterações pequenas e rastreáveis.
3. Execute:

```powershell
python tests/validate_squad.py
python tests/smoke_test.py
```

4. Abra um pull request explicando objetivo, arquivos afetados, validação e risco residual.

## Commits

Use mensagens objetivas:

- `feat: adiciona workflow de roteiro científico`
- `fix: bloqueia hook factual sem fonte`
- `docs: esclarece fluxo do reels-chief`
- `test: cobre roteamento de atualização de IA`

## Regras críticas

- Não inventar evidência, número, estudo ou resultado.
- Preservar uma decisão por vez e até três opções.
- Tema abaixo de 6/8 não vira roteiro.
- Hook precisa ser aprovado antes do roteiro.
- Texto visual é somente legenda sincronizada.
