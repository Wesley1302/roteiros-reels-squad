# Roteiros Reels Squad

Use `config.yaml` como manifesto. A entrada única é `RRS-chief`; o usuário vê `reels-chief`.

## Ativação

1. Leia `config.yaml`.
2. Inicialize `state/RRS-journey-state.yaml` a partir do template se necessário.
3. Rode `tasks/RRS-run-initial-diagnosis.md`.
4. Escolha o workflow apropriado e siga os handoffs declarados.

## Regras invioláveis

- Uma decisão por vez; no máximo três opções por rodada.
- Tema abaixo de 6/8 não vira roteiro.
- Dados atuais, técnicos ou controversos exigem fonte; sem fonte, hipótese ou placeholder.
- Hook precisa ser aprovado antes do roteiro.
- Exatamente um CTA.
- Texto visual é somente legenda sincronizada; nenhum título, card ou overlay extra.
- Não prometer viralização, seguidores, retenção ou vendas.
- Adaptar mecanismos das referências sem copiar história, fala ou promessa.
