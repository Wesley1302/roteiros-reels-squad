# Roteiros Reels Squad

Squad task-first para criar Reels úteis, verdadeiros e graváveis — do entendimento do criador ao aprendizado pós-publicação.

Porta de entrada: `reels-chief`.

## Filosofia

Tema forte antes de hook. Hook forte antes de roteiro. Evidência antes de afirmação. Produção simples antes de efeitos. Publicação vira aprendizado, não julgamento.

## Ordem canônica

`Diagnóstico → Mapa do criador → Tema → Pesquisa → Score → Ângulo → Hook → Estrutura → Roteiro → Validação → Gravação → Publicação → Aprendizado`

## Uso rápido

1. Ative `reels-chief`.
2. Diga se quer encontrar um tema, criar um roteiro, melhorar um rascunho ou analisar um Reel publicado.
3. Responda uma decisão por vez.

Consulte [guia de uso](docs/RRS-usage-guide.md) e [arquitetura](docs/RRS-architecture.md).
