# Guia de uso

## Entrada recomendada

Use `reels-chief` e diga em uma frase o que quer:

- “Quero encontrar temas sobre IA.”
- “Tenho um tema e quero um roteiro.”
- “Quero melhorar este rascunho.”
- “Publiquei e trouxe as métricas.”

O chief escolhe o workflow. Você não precisa chamar especialistas internos.

## Atalhos visíveis

| Comando | Uso |
|---|---|
| `reels-temas` | descobrir e pontuar temas |
| `reels-pesquisa` | verificar um tema atual ou técnico |
| `reels-angulos` | explorar pontos de vista |
| `reels-hooks` | criar e aprovar hooks |
| `reels-roteiro` | estruturar e escrever |
| `reels-revisao` | auditar precisão e clareza |
| `reels-direcao` | preparar gravação e edição |
| `reels-metricas` | aprender com publicação |

## Saída padrão

O squad entrega tema e score, ângulo, mecanismo do hook, roteiro em cinco blocos, legenda sincronizada, direção simples e uma hipótese pós-publicação.
