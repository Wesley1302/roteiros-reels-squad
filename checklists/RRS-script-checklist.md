# Checklist de roteiro

- [ ] Hook aprovado permanece coerente.
- [ ] Qualificador deixa claro para quem é.
- [ ] Cada bloco adiciona dado, exemplo, passo ou virada.
- [ ] Payoff entrega o que o hook prometeu.
- [ ] Linguagem serve ao público leigo sem distorcer o fato.
- [ ] Duração é realista; tema complexo virou série quando necessário.
- [ ] Há exatamente um CTA.
- [ ] CTA combina com o objetivo e o ativo entregue.
- [ ] Não promete viralização, seguidores, vendas ou retenção.
- [ ] Texto visual é somente legenda sincronizada.

PASS: todos os itens verdadeiros.
